# AppleNotesPro 0.6.3：Agent 简化为 Prompt + Skill

2026-10-11。已安装。用户明确将MCP与Tools暂缓，本版只交付Prompt与Skill。

## 使用

设置→Agent选择一个角色，编辑名称与一份完整的角色Prompt，再勾选需要的Skill并保存。回到Notes，在快捷AI或原文批注的Agent选择器中切换角色。

不再要求分别填写目标读者、写作目的、判断视角、表达风格、质量标准和补充规则，也不再在Agent主界面展示Skill适用动作和快捷动作排序。模型连接继续独立配置。

Prompt说明角色是谁、如何处理材料和应遵守的要求。Skill提供可复用的方法及资源。公众号、个人笔记、汇报保留为可编辑预设，各自使用一段精简的角色说明。

公众号从读者的问题、证据与边界组织短文；个人笔记用简短标签区分观察、依据、未知与下一步；汇报强调专业、结论先行和指标口径。三者都受用户批注、事实约束和当前编辑动作范围限制。

## 数据与兼容

Agent配置使用schema 2，核心角色文字只保存`prompt`。旧的六个文本字段只存在于兼容读取类型中，不再作为当前Agent模型或编辑器字段。

迁移前按原始字节备份`agents.json`，名称为`agents-before-prompt-v3-<UUID>.json`；迁移失败不覆盖原文件。自定义角色的各段文字逐一合并到Prompt，原ID、默认角色、Skill引用和此前动作绑定保留。只有完全匹配未编辑内置文案的角色会升级为精简预设。

历史草稿继续保留当时的角色文字、批注和候选，不自动换成新的内置Prompt。要在已有修订中使用更新的角色，可在Notes中重新选择该角色或使用“更新当前角色与Skill”。打开草稿不会自动发模型请求。

0.6.2的请求取消、超时、停止全部和草稿恢复机制继续保留。MCP／Tools没有出现在本版配置、依赖或执行路径中。
