> 2026-10-10后续：已完成[三场景真实模型验收](REAL-AGENT-SCENES-0.6.0.md)。批注/最终写回/撤销通过；公众号与个人笔记风格区分偏弱，汇报首次空行问题经格式修正后通过。下文原始合成验收和钥匙串阻塞保留为阶段记录。

2026-10-10。已实现并安装。设置拆为“模型连接 / Agent / Skill”，公众号、个人笔记、汇报三种场景可以直接在Notes中选择。

## 使用

- 设置 → 模型连接：只配置服务、协议、模型ID、密钥、默认连接和连接测试。
- 设置 → Agent：内置公众号、个人笔记、汇报；支持新建、复制、编辑、删除和设为默认。每个角色可设置目标读者、目的、视角、风格、质量标准、补充规则、Skill绑定、Skill适用动作和优先显示的快捷动作。
- 设置 → Skill：统一管理“简单指令”和“Skill包”。简单指令可编辑提示词与适用操作；Skill包可导入/同名更新，并显示使用它的角色。被角色引用的包不能直接从UI移除。
- Notes选中文字 → AI写作：直接选择Agent，再点击润色、纠错、摘要等，或填写修改要求。可以在已有候选上切换角色继续修改。
- Notes原文批注：右下角也提供同一组Agent。先选角色、添加局部意见，再统一优化；切换角色保留原文批注、候选和版本历史。
- 原文批注菜单“更新当前角色与Skill”明确更新任务快照。运行中的任务保持原版本，后续生成不会被后台设置修改打断。

默认模型不会随着角色切换而改变。升级用户继续默认使用“默认助手（原配置）”；想默认采用某个场景，可在Agent设置设为默认。已保存的笔记批注会话恢复自己的角色。

## 三种角色

| 角色 | 核心取舍 |
|---|---|
| 公众号 | 从读者的问题、认知与阅读体验组织观点；解释必要术语，保留作者立场，避免虚构故事、空泛夸大和未经要求的营销号召 |
| 个人笔记 | 便于自己理解和回顾，梳理概念和因果；保留疑问、不确定性和个人声音 |
| 汇报 | 从目标、结果、影响、风险与待决策事项组织已有信息；结论先行，专业简洁，不编造收益、风险评级或负责人 |

角色风格服从本轮用户要求、局部批注和动作范围。纠错限制在语法/拼写/标点，翻译不增加营销内容；它们默认不加载改写风格Skill，可由用户在角色中修改适用动作，但动作范围仍有效。

## 共用内核

`AgentContextBuilder`给快捷AI和批注修订构建相同的角色规则。快捷动作使用对应操作约束和已绑定的适用Skill；文本资源在有界体积内完整附带，不声称执行脚本。批注修订继续使用plan → revise → audit → 可选repair，并核对角色质量标准、所有批注和事实约束。

每轮固定`AgentSnapshot`，包括角色版本与Skill内容。候选历史保存当时角色；发送下一轮历史时不附带旧角色的整套规则，以避免原角色继续压制新角色。Skill安装身份与内容指纹分开，同名包更新后角色引用保持，已有任务快照不被改写。

与现有能力保持一致：不引入脚本执行、多Agent并行或后台知识库。角色、Skill读取只在配置/会话/明确请求发生，不加入Notes日常键盘和选区监听路径。

## 迁移与保存

首次迁移创建agents.json，并在before-agent-migration-UUID目录备份旧设置和启用Skill快照。旧systemPrompt和writingPreferences原样进入“默认助手（原配置）”；已有提示词、模板、连接ID、默认模型与Keychain引用不改。

原settings.json和writing-skills.json保留原位置。旧草稿可解码；缺少角色时以兼容助手或当前显式选择补齐，原批注和Skill快照保留。新增Agent只存角色规则与能力引用，不存密钥。迁移或读取失败时阻止普通覆盖。

本机已核对迁移前后settings.json语义完全一致；原自定义提示词及密钥引用相同，新增四个角色（兼容助手加三个场景）。临时验收模型连接已移除，原默认连接恢复。

当前“导出AI与模板配置”仍针对原设置文件；完整Agent/Skill库的一体化导入导出不属于本版。

- 在合成Notes笔记APN-ROLE-1010 Agent场景验收中，快捷AI依次切换公众号、个人笔记、汇报，各完成一次生成，继续使用上一稿。
- 从快捷AI进入原文批注，继承汇报角色；保存一条包含数字及限制条件的批注后，在原文右下角依次执行三种角色优化。
- 合成服务记录12次请求：每个角色一次quick与plan/revise/audit三阶段。全部请求包含读者、目的、质量标准；各阶段带入Humanizer-zh，原批注在三轮中保持1条；后两轮包含候选历史。
- 本机草稿的三次生成版本分别记录公众号、个人笔记、汇报，且原批注保留。
- 汇报候选写回真实Notes，标题保留；一次原生Undo完整恢复原文。
- 另存个人笔记角色与批注，退出/重启后恢复角色“个人笔记”和原批注；恢复原模型配置后仍可继续使用角色。
- Release与严格签名验证通过，临时测试服务停止。只使用合成笔记，没有发送用户真实笔记。

本版真实服务尝试在Keychain读取处要求系统确认，未得到真实模型输出。上述端到端输出来自明确标记的本机合成服务，证明配置和请求链路，不是三种角色文风质量的实测。若当前连接提示钥匙串确认，在模型连接点击“用合成文本测试”，由用户完成macOS系统认证；不在聊天中传递系统密码。
