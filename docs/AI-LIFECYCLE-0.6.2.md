# AppleNotesPro 0.6.2：AI 任务与连接生命周期

2026-10-11。已安装并验证。解决用户离开操作后请求继续运行、缺少整轮时限，以及过期结果影响后续任务的问题。完整交付状态见根目录 VERIFICATION.md。

## 当前采用的会话方式

本机修订草稿保存原文、批注、角色与Skill快照、候选和有限历史，不是服务端持续运行的Agent。每次主动优化独立发出HTTP流式请求；快捷修订最多携带4轮历史，批注修订最多携带6个历史版本。请求正文仍受已有大小限制。

Responses请求设置`store: false`，不创建Conversation，不发送`previous_response_id`，不启用`background`。本版同时为直连`api.openai.com`的Chat Completions显式设置`store: false`；其他兼容服务保留原协议，避免加入其未支持的字段。用户配置的中转服务是否保留或继续执行上游任务，取决于中转服务的实现，客户端不能声称已经确认上游停止。

已核对[OpenAI官方后台模式文档](https://developers.openai.com/api/docs/guides/background)：前台同步响应通过终止连接取消；带`background: true`的响应才使用服务端cancel API。当前应用没有创建这类后台响应，因此不为每次请求额外创建远程任务或轮询。官方的[会话状态说明](https://developers.openai.com/api/docs/guides/conversation-state)区分响应存储和持久Conversation；关闭响应存储不等于对服务商所有日志保留政策作出承诺。

## 结束规则

| 事件 | 行为 |
|---|---|
| 点击停止、关闭AI面板、替换当前任务 | 取消Swift任务，同时主动注销本次URLSession、断开传输；旧回调不能更新新任务 |
| 原文批注切到其他应用、笔记或窗口 | 暂停定位，并停止进行中的生成；保留批注、上一稿和未保存气泡输入 |
| 笔记正文已变化 | 按已有目标检查停止修订，禁止对旧范围写回 |
| 系统休眠、用户会话离开、应用退出 | 统一停止已登记的AI任务；恢复后不自动重试 |
| 90秒无完整模型事件 | 中断请求；SSE注释心跳和零散字节不续期 |
| 单个HTTP请求达到4分钟 | 即使持续有输出，也结束连接 |
| 一次快捷操作／连接测试达到5分钟 | 连同等待凭据的时间一起结束本地任务，不再发后续请求 |
| 整轮批注修订达到10分钟 | 停止后续分析、修订、复核或修正；已有批注和候选保留 |
| 正常完成或失败 | 注销运行记录并释放计时器、任务句柄和网络会话 |
| 恢复本机草稿 | 只恢复数据；点击“统一优化”后才启动新一轮请求 |

这里的90秒是协议事件进展时限，不是判断模型思考质量。整轮修订仍最多执行分析、修订、复核及一次修正，不做网络失败后的自动重试。模型超时会给出明确状态；部分流式结果不能自动写回Notes。

运行登记只含本机任务ID、截止计时器和取消回调，不存笔记内容或远程会话ID。设置→模型连接显示运行数量，提供“停止全部 AI 任务”。停止只影响生成，不中断已经开始的原生Notes写入事务。没有进行中的任务时，不保留模型连接或后台保活计时器。

钥匙串系统认证窗口不能被普通取消回调强制关闭。如果在认证期间停止，迟到的认证结果也不会发起模型请求；用户可在系统窗口取消认证。此处不改变钥匙串权限。

## 实现

- `AIRunRegistry`：快捷AI、原文批注、独立修订和模型测试共用登记、取消、整轮时限与系统事件处理；不持久化运行状态。
- `ModelRequestLifetime`：线程安全的进展／绝对时限，取消时调用本次请求专属URLSession的`invalidateAndCancel()`，不等待下一个流片段。
- `ModelClient`：请求前检查取消；所有成功、失败、超时路径释放会话；错误不会包含密钥或服务商原始响应正文。
- `NativeNotesAnnotationController.suspend()`：从仅隐藏UI改为同时停止修订，恢复定位不会重启模型。
- 两个界面模型保持每次生成的UUID校验，超时与停止同样作废旧回调；本机草稿可正常恢复。

## 验证

本轮针对性28项测试通过，涵盖已有快捷AI、批注修订与新增生命周期。HTTP测试使用本机合成服务，实际观察对端连接关闭，分别覆盖静默、心跳、无限进展、显式取消和请求开始前取消。测试时将时间缩短为0.2／0.7秒；产品默认仍为90／240秒。

模型层测试覆盖离开笔记后保留批注、整轮超时、同时停止两个请求、系统休眠与会话离开事件、迟到响应不覆盖新任务、正常完成后无残留截止计时器、恢复草稿不发请求。停止操作不执行Notes写回。

旧实现的直连OpenAI Chat请求未显式禁用存储，回归先失败后通过。旧实现的普通取消HTTP测试本来就能通过；本版增加显式传输取消和超时保障，不把该旧路径误写成已证明泄漏。证据：`build/lifecycle-red.log`、`build/lifecycle-green.log`。

安装后的应用实测：未保存的合成连接启动时显示1个运行任务，点击“停止全部 AI 任务”后显示0；HTTP对端确认连接关闭，应用进程没有残留TCP连接。恢复原连接后，settings.json、agents.json、writing-skills.json和当时的公众号草稿指纹均未改变，临时密钥未保存。证据在`build/install-verification-0.6.2/result.json`。

后续三个精简角色已在0.6.3完成[真实模型与原生写回验收](REAL-AGENT-SCENES-0.6.3.md)，全部首轮写回及一次撤销通过；结束时任务数为0，进程没有残留TCP连接。本页HTTP故障测试与实际模型验收分别记录。
