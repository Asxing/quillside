# AppleNotesPro 新品牌命名初筛：名称包含 Notes

调研日期：2026-10-12（Asia/Shanghai）。本轮只研究与提出候选，不注册域名、创建账号、修改应用或购买商标服务。此前不含 Notes 的候选已经按用户新偏好调整，旧词根结果仅作备查。

产品定位：原生 macOS Apple Notes 写作增强，在当前正文中批注、汇总优化、切换角色 Prompt 与 Skill，并提供快捷编辑、模板和显式反向链接。品牌应传达安静的写作陪伴，并包含完整 **Notes**；独立品牌下以“适用于 Apple Notes”解释兼容对象。

## 1. 推荐保留的完整品牌

含义、中文搭配和取舍为产品命名建议；重名一栏为实际检索事实。

| 完整名称 | 中文搭配建议 | 产品适配 | 缺点与检索边界 | 本轮结论 |
|---|---|---|---|---|
| **Quillside Notes** | **笺伴** | quill（羽毛笔）＋ side（身旁）＋ Notes，表达写作时在旁协助。覆盖批注、优化、快捷编辑，给后续能力留空间。读音可按“kwil-side notes”记忆。 | 名称较长；需副标题解释它增强 Apple Notes。Quillside 词根已有异业业务，因此不能说从未被使用。 | **本轮未检出明显同名软件**。完整名称公开网页与 App Store 定向搜索未找到明显同名产品；GitHub 全局 `quillside in:name` 返回 0。 |
| **Marginlet Notes** | **旁笺** | margin（页边）＋ -let（小型事物的联想）＋ Notes，突出贴在正文旁的小批注，贴合轻量原文交互。 | 容易让人以为仅提供批注；中文和副标题需展示编辑优化能力。与 MarginNote 共享 margin 词根，最终须另查近似商标，不能只看完整名。 | **本轮未检出明显同名软件**。完整名称公开网页与 App Store 定向搜索未找到明显同名产品；GitHub 全局 `marginlet in:name` 返回 0。 |

希望强化整体“写作伙伴”定位，优先 **Quillside Notes**；希望围绕“原文批注”建立识别，优先 **Marginlet Notes**。不为凑足三个强候选而忽略已发现的同类产品。

建议对外排列：

> **Quillside Notes · 笺伴**
> 适用于 Apple Notes 的原生写作助手
> A native writing companion for Apple Notes.

这是可供审阅的命名建议，并未修改应用。Notes 是类别词，不应将它包装为 Apple 授权。完整品牌仍需商标、域名、账号分别核验。

## 3. 检索方法与证据边界

- 公开网页：搜索完整名称和紧连写法，例如 `"Quillside Notes" app github`、`"Marginlet Notes" app github`、`"QuillsideNotes" OR "MarginletNotes"`；对 App Store 追加 `site:apps.apple.com`。
- 短组合补查 `"NotesQuill"` / `"Notes Quill"`、`"NotesLilt"` / `"Notes Lilt"`，追溯到官方产品站或作者仓库，过滤 OCR 相邻词拼接等噪声。
- GitHub：读取官方全局公开仓库 REST API，用词根包含查询覆盖 QuillsideNotes、quillside-notes、quillside_notes 等形式；Wren 对紧连、连字符、下划线分别查询。GitHub 仓库名不能包含空格，分词产品名不能直接等同于仓库 slug。
- Apple：同时读取官方 iTunes Search API 的 `media=software`、`country=us/cn` 搜索返回，比较名称归一化后的完整匹配。US 返回了相关软件结果，但上述新组合没有完整同名匹配；CN 本轮所有这组查询返回 0。搜索 API 不是完整全球商店目录或商标查询，也不把地区零结果作为无冲突保证。未对所有历史下架/隐藏应用作穷尽检查。
- GitHub handle、仓库名称、域名、商标分别判断。不同账号能有同名仓库；全局公开仓库搜索为零不证明 handle 可注册或商标没有冲突。
- 本轮结论仅“检出已有软件”“未检出明显同名软件”或“存在相近名称线索”；不作“完全可用”“可注册商标”“没有法律风险”承诺。

## 7. 定名与实际改名的后续动作

1. 选择一个完整主候选和一个备用，补查中美目标商品/服务类别的相同与近似商标；Marginlet Notes 特别检查 MarginNote 相关近似，Quillside Notes 检查词根已有业务及目标软件类别。
2. 对完整品牌对应域名、GitHub handle 和仓库归属分别核验。旧词根域名状态不等于完整组合域名状态，RDAP 404 也不保证普通价格、无保留或必能注册。
3. 用户选定具体名称后统一 App 显示名、官网、README、仓库和安装包。保留 MIT 与上游第三方版权；Keychain、旧数据目录、模型配置和系统授权按迁移方案处理。

本轮没有改动应用品牌，也没有替用户购买或注册任何外部资源。

## 8. 中文名与最终判断

中文搭配是原创建议，不是已有品牌的官方译名。主代理在 2026-10-12 分别检索了“笺伴”＋软件/笔记/app、“旁笺”＋软件/笔记，以及两者＋商标；本轮公开网页未检出明显同名笔记软件。普通搜索引擎不能完整覆盖中文商标、同音近似或未索引的小程序，因此不能写成中文名已通过核名。

- **笺伴**：强调在写作过程中的陪伴，中文比英文更直观，适合覆盖编辑、批注与 AI 优化。需要在品牌初期让用户认识“笺”字。
- **旁笺**：强调原文旁的意见和小批注，产品交互联想更直接；如果使用它，首页仍需说明快捷编辑、角色与 Skill 的完整范围。

综合建议：以 **Quillside Notes / 笺伴** 为品牌表达的首选，以 **Marginlet Notes / 旁笺** 为备用。前者适合整体写作助手，但 Quillside 根词域名已经注册、存在异业名称线索；后者根词域名也未查到登记，但需特别核查与现有 MarginNote 的近似问题。各有待核验事项，不将“首选”误写为法律上更安全。

正式商标检索尚未完成。美国入口为 [USPTO 官方检索](https://www.uspto.gov/trademarks/search)；中国商标局公开查询入口本轮抓取未成功取得结果。完整名、词根、中文名和读音近似应结合实际商品/服务范围核验。当前交付是产品命名初筛与公开占用调查，供用户选择下一轮核名对象，不是商标可注册保证。
