2026-10-08。用户已确认不做原厂账号/订阅计费、远程遥测、Floating notes/Vim 和复杂模型路由。本轮围绕已约定的编辑、模板、原位 AI 与正文反链完善，搜索/知识库不恢复，笔记文件导入导出继续延期。

## 本次落实的改动

| 原问题 | 0.3.1 实现 | 证据与边界 |
|---|---|---|
| 鼠标换到新行后旧键盘 buffer 导致 Markdown 漏触发 | 删除 buffer 驱动；空格前捕获实际正文/光标，空格提交后核对变化和同一编辑目标，再匹配行首9类触发 | EditorContextTests 验旧正文、换行、emoji、无效范围和非行首；原生 Notes 实际触发仍待验 |
| slash 字符缓冲与正文不同步 | 筛选读取实际 AX token；被本应用消费的确认键与交给 Notes 的原始键明确区分；执行前重新核对同一编辑上下文 | 官网 aliases/边界回归继续通过；快速输入/候选态仍待实机 |
| 表格子编辑器可能被当成整篇笔记 | NotesEditorContext 根据实际正文标识与祖先结构区分正文、单元格和未知编辑器；无选区时只接受正文；明确选中的单元格文字可处理 | 角色/祖先/范围策略回归通过；未知结构拒绝，不猜测全文 |
| 输入法候选键可能被 slash 吞掉 | 仅当组合状态明确安全或使用直接键盘布局时接管导航/确认；输入法组合状态无法确认则交给系统，菜单可鼠标点选 | 这是明确的保守边界：未知组合态时不承诺 Space/Return 快捷提交；须实际验证中文输入法 |
| Markdown 单项开关只有底层机制 | 快捷键设置中增加9类触发的独立开关，保存到既有偏好并实时应用 | 单项关闭、其他触发保留、重载与未知键回归通过 |
| 多个浮动面板共用 Boolean，关闭一个可能提前恢复按键处理 | 输入占用改为 AI/模板/反链各自持有；显示面板时隐藏底部动作栏；切换应用时关闭非编辑面板 | 多持有者释放测试通过；AI离开Notes时不强行抢回焦点 |
| AXSelectedText 写回不等于进入原生撤销栈 | AI与模板纯文本、正文反链RTF统一执行一次 Notes 原生粘贴；完整目标校验和文字读回，失败不自动换路径重试 | 通过设置范围后调用当前可用 Paste 菜单；撤销实际行为仍待实机证明 |
| 写回时破坏用户剪贴板 | 保存全部可读取的原剪贴板类型，只在本次剪贴板版本未变化时恢复 | 用户在写入期间复制新内容时不覆盖；无法读取的延迟剪贴板表示不承诺恢复 |
| 半个 UTF-16 emoji 范围被 Foundation 范围转换放行 | 增加明确的代理项边界检查，同时用于选区保护/正文上下文/写入计划 | 回归实际发现旧实现产出“�”，修复后拒绝损坏范围 |
| 模型流逐行解析不支持多行 SSE | UTF-8 按字节限长组装行，处理 LF/CR/CRLF/BOM、注释、多 data 行与空行分帧；NDJSON 独立结束处理 | 真实 localhost 四协议服务改为多行 SSE/CRLF并继续拆分网络字节，全部通过；按 [WHATWG SSE](https://html.spec.whatwg.org/multipage/server-sent-events.html#parsing-an-event-stream) 实现，EOF不伪造缺失事件结束 |
