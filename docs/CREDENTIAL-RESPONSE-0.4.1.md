# AppleNotesPro 0.4.1 授权与界面响应修复

2026-10-09，已安装。本轮继续真实模型验收时，采样确认旧版“用合成文本测试”在主线程等待 SecItemCopyMatching，设置界面不能响应；已完成的单次授权没有跨修订阶段复用。

## 修复

- 模型测试、快捷 AI、批注修订共用专用后台队列读取钥匙串，界面线程不再执行模型密钥读取。
- 仅将本进程已经成功取得的密钥暂存在内存，供后续修订阶段复用；不写入文件，不调整 Keychain ACL。未授权、读取失败、缺失的密钥不缓存。进程退出后缓存消失。
- 更新或删除密钥时清除缓存并推进修订标记，迟到的读取结果不能重新恢复旧密钥。缓存以独立凭据 ID 隔离。
- 测试过程中展示当前状态和“停止测试”。取消后即使系统读取随后返回，也不会继续发出模型请求或覆盖新状态。

## 已验证

- 先用同步读取的最小复现运行回归测试，捕获“在主线程执行”和“后续阶段再次要求确认”两个失败；修复后通过。
- 新增 5 项回归覆盖后台读取、四阶段授权复用、连接隔离、失败不缓存、密钥失效和取消。全部 213 项测试中 212 项已执行通过，1 项旧宣传截图跳过（界面渲染单独补跑通过），34 套件。
- 实际安装包在系统等待钥匙串期间保持可访问、可响应，并显示“停止测试”；旧版本此时 AX 操作超时。
- Release 构建和严格签名验证通过，沿用原 bundle ID 与开发签名。原模型配置与本机修订草稿保留。
