# 当前功能 · Quillside 0.7.4

原生Apple Notes写作伴侣，主要行为在Notes中完成，设置只负责配置。产品处于开发者预览；当前界面以中文为主。

| 功能 | 当前行为 |
|---|---|
| 原文批注 | 选句留意见，多处批注保留，整体意见统一修订，候选与历史保存在本机 |
| AI编辑 | 润色、纠错、翻译、续写、自定义要求、继续修改、预览与确认写回 |
| Agent与Skill | 名称、一份角色Prompt、所选Skills；三种内置场景，MCP/Tools暂缓 |
| 模型 | 内嵌Pi 1.2.0，API Key、兼容连接与受支持订阅登录；账户/地区/模型范围由服务方决定 |
| 原生编辑 | 可配置工具条、Markdown快捷格式、Slash原生命令、模板 |
| 反链 | 只读定位引用来源，预览后写入正文链接，主动更新并保护手改区域 |
| 安全写回 | 校验目标/正文/选区，单次原生粘贴与一次撤销，取消/失效后拒绝旧结果 |
| 生命周期 | 超时、停止、离开笔记、休眠与退出取消请求，草稿恢复不自动联网 |
| 官网 | 简体、繁体、英文；交互示例与真实中文验收译文分开标注 |

不提供独立知识库、独立搜索、后台全库同步；Notes/Obsidian完整文件交换、自动更新、MCP和工具执行均非首发前置条件。基础Markdown复制不是完整附件导出。

当前实机覆盖Apple Silicon/macOS26.5.2与合成笔记，未声称覆盖所有macOS、IME、多显示器与文档结构。详见[验证](../VERIFICATION.md)和[开发构建](development/BUILDING.md)。历史对标表不等于当前独立功能数。
