## 0.1.2 工具条进展

新增 [工具条实现与验收记录](TOOLBAR-IMPLEMENTATION.md)。默认十项现在与已观察的 ProNotes 控件集合一致；保留六项可选格式。设置支持 List.onMove 拖动排序、上/下移、显隐、恢复默认与版本化持久化。全部隐藏时关闭浮层，面板按项目数和错误反馈调整大小。

字体、链接、对齐、清单、表格等动作统一查找 Notes 当前菜单。菜单禁用、歧义或读取失败时停止并反馈；只对菜单公开的有效快捷键做后备投递，不使用盲目的默认键码。执行前验证进程、窗口、正文摘要和选区。新增 `/link`，Markdown/slash 格式失败时在没有后续编辑的条件下恢复触发串。

新增测试覆盖菜单上下文与别名、禁用/歧义、快捷键元数据、视图模型路由、错误反馈、排序与重新读取、全部隐藏、未来/损坏配置和尺寸上限。138 项测试中 136 项执行通过、2 项可选用例跳过；包哈希见验证记录；所有真实 Notes 菜单、字体面板、拖动、IME、全屏与撤销仍未验收，不能把这些项标成完整完成。

## 0.1.3 模板与搜索进展

新增 [模板与搜索实现记录](TEMPLATES-SEARCH-IMPLEMENTATION.md)。模板已接入动态 slash 目录，自定义快捷词可直接插入，`/template` 打开中文搜索面板。重复提交和写入失败不会自动重试，实际选区改变也会拒绝旧快照。

搜索已改为独立面板，支持初始聚焦、上下选择、Return/双击打开、Esc 关闭、刷新及标题优先排序。新增强错误语义读取路径，不把 SQL/schema 错误显示为零结果，并隐藏锁定笔记摘要。迟到加载被取消标记和 generation 隔离。

两个搜索热键可分别录入/清除。注册冲突或持久化失败保留旧绑定，录入期间暂停自身全局注册；同一组合避免双路消费。当前 157 项测试中 155 项执行通过，2 项可选 GUI/数据库测试跳过；真实注册和操作仍未验收。

## 0.1.4 反链与集合身份进展

新增 [数据完整性说明](DATA-INTEGRITY-IMPLEMENTATION.md)。生产反链路径在同一只读事务内取得元数据和正文，失败/加载/部分覆盖/真正无结果分别呈现，过期构建与忙碌刷新按 generation 合并。正文已删除的链接附件不再生成反链。密码保护、未解析和复杂内容会明确降低覆盖范围，尚不声称表格内部链接完整。

知识索引升级为 schema 2，使用账户/文件夹身份筛选，名称只用于显示。旧 Notes 数据没有账户身份时按来源隔离，刷新后补全；不自动扩大选定范围。正文读取按已选 UUID 查询。真实临时库验证了 WAL 一致性、迁移保留和回滚、重名隔离与重命名稳定。

当前 175 项测试中 173 项执行通过、2 项可选用例跳过。真实数据版本、账户关系、iCloud 同步和 UI 仍待实机验收。

## 0.2.0 范围收敛与正文反链

根据用户最新指示，当前优先完善编辑、模板、当前内容 AI 和反链。独立知识库、笔记搜索与搜索热键已移出编译目标，历史代码保留在 legacy。笔记文件导入导出延期；现有 AI/模板 JSON 配置备份及基础 Markdown 复制保留。

正文反链新增预览与局部富文本粘贴；用户修改的区域拒绝覆盖；部分来源只能补充，不能删除原列表；持久化生成区历史以支持去重与撤销后的识别，读取反链时排除生成的返回链接。AI 输入装配只接收当前显示材料，旧默认问答指令精确迁移，自定义提示词不删除。

当前 159 项测试，158 项执行通过、1 项可选截图用例跳过，24 个 suite；真实数据库测试只使用本轮两篇合成笔记的实际编码正文。移出的搜索/知识库测试保留在历史目录，计数减少源于范围调整。安装包和实机边界见 [验证记录](../VERIFICATION.md)。

## 0.3.0 原位 AI 与统一设置

用户明确要求日常操作在 Notes 内闭环，后台仅配置。独立写作工作台已归档到 legacy/standalone-workspace，全部 AI 入口改为非激活浮动面板，支持快捷动作、自定义要求、停止/重试、可编辑结果、复制、替换/插入；成功后回到 Notes。模型/提示词与模板集中在单一设置窗口，启动不自动打开后台。

模板选择与正文反链预览也采用 Notes 旁的非激活面板。共享输入隔离避免 event tap 将面板内文字误判为 Markdown 或 slash。新增测试覆盖不自动请求、迟到结果隔离、目标变化、写入失败不重试和屏幕边界。167 项测试中166项通过，1项旧截图用例跳过；当前原生 AI 视图渲染已检查。

实机已检查统一设置通用、AI 模型/提示词及模板页面。系统状态明确显示 OpenNotes 辅助功能/完全磁盘访问未授权，自动化已授权，不能把缺少授权的 Notes 热键无响应判定为实现通过或代码缺陷。真正原位生成与写回须完成授权后继续验收。

## 本轮实机证据与阻碍

本次 Mac 可操作，建立了两篇名称以“OpenNotes 验证 20261008”开头的合成笔记。验证了 Notes 接受正文原生 URL 链接、显示可点击对象、撤销一次插入，以及从 A 点击链接打开 B。以上验证来自界面工具操作 Notes，不能代替 OpenNotes 新按钮的完整流程验收。
