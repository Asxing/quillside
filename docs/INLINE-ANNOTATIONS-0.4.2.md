# AppleNotesPro 0.4.2 原文划线与批注气泡

2026-10-09。按用户提出的Codex式批注交互调整：默认单栏正文，选区附近添加意见，原文上保留划线和小气泡；取消常驻左右两栏。

## 使用

1. 在Notes选中要修订的连续范围，打开AI写作 → 批注修订。
2. 在新界面的正文中拖选一句话或一段文字，松开后出现“添加批注”。支持键盘和辅助功能选区，右键菜单也提供入口。
3. 点击按钮，在选区附近的小气泡直接输入意见，点击“保存批注”或按⌘↩。
4. 保存后出现划线与行旁小气泡。点击划线或气泡可查看、修改、停用或删除意见；同一行多条批注显示数量，可在气泡菜单切换。
5. 重复选句，最后填写整体要求或直接点击“统一优化”。“批注 N”按需打开所有意见和每条处理说明；默认不占据正文旁边的栏位。
6. 检查候选结果后替换选区或插入后方。批注历史、Skill、草稿恢复及Notes写回保护沿用原实现。

模型和全文上下文开关保留在顶部；更新Skill、加入Notes选区和从当前选区新建收进“修订选项”。默认窗口宽680、最小宽560，正文使用完整宽度。

## 原生实现

正文为NSTextView。选区按钮、批注标记、NSVisualEffectView与SwiftUI意见框全部位于同一个原生窗口，不依赖外部网页或独立编辑窗口。意见框自动获得焦点，粘贴不会被发送至候选正文。滚动和换稿时关闭旧气泡；点击保存使用打开气泡时固定的版本、范围与原句，不依赖后来改变的焦点。

保存前验证版本ID、UTF-16范围和引用原句。旧版本、删除后的批注、被修改的原句均拒绝使用旧定位。新增和编辑先保存文件，再更新可见草稿，保存失败不会假装成功。批注仅标记对应版本；历史意见继续参加后续优化，在汇总浮层查看。
