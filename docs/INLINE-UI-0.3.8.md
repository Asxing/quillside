# 0.3.8 Notes 内浮层与 AI 界面

2026-10-09。目标是减少独立应用窗口感，功能及编辑保护沿用0.3.7。

## 展示变化

- AI、模板选择、正文反链预览统一为borderless非激活NSPanel；去除独立标题栏和红黄绿按钮，用紧凑关闭按钮与Escape处理。
- 使用统一12点圆角、柔和材质、细边框与系统阴影；暖中性色和随明暗外观变化的金色强调，常用工具条降低阴影强度。
- AI初始面板392×246点，六项常用动作和修改要求优先；其他原有提示词保留在“更多动作”。原文、模型与语言按需展开，设置入口在展开区。
- 生成结果高度按内容在64–240点之间增长，短结果面板约392×244点；长结果滚动，复制/重试/应用按钮始终保留。原文对照同样按内容高度显示。
- 减少正常状态重复说明和地址展示，错误/目标失效提示继续显示；输入区和继续修改保留在原位。
- AI浮层按捕获选区与Notes窗口可用范围定位；模板宽380点，反链预览宽400点，空反链提示减少留白。

参考了[ProNotes官网](https://www.pronotes.app/)在Notes旁展示格式工具和AI内容的方式，官网演示中可见紧邻笔记的轻量AI浮层。设计参考不等于恢复原厂内部实现；本机ProNotes主窗口未成功读取，没有据此宣称完成原厂AI流程对照。

## 实机与视觉验证

真实Notes合成笔记“AppleNotesPro 界面验收 1009”上验证：

- 无标题栏的小面板在选区旁打开；默认不展开模型配置。
- 模型/语言展开与收起，原文对照展开与收起，更多动作中的续写均可用。
- localhost合成服务收到两次明确触发的请求；润色与续写生成候选。
- 替换选区、插入后方、前后文保留及一次撤销通过。首个AX读回有粘贴中间态，最终完整读回才判定通过。
- /template显示两项真实模板，选择阅读模板后插入及撤销通过；模板截图的离屏List渲染不代表运行时列表，实际界面已核对。
- 正文反链的空结果/关闭界面可用；反链编辑事务未改动，已有防覆盖回归继续通过。

浅色、深色、短结果、长结果和目标失效提示均渲染并检查。194项测试中193执行通过，1项旧宣传截图跳过，30套件；包含模型状态、输入路由、写回保护、模板与反链回归。截图位于build/inline-screenshots-0.3.8。
