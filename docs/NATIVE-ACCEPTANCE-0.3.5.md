# OpenNotes 0.3.5 本机原生验收

2026-10-08；macOS 26.5.2 arm64，Apple Notes 英文菜单。通过 CUA 操作真实原生应用，只修改命名为 OpenNotes 的合成验收笔记。以下是观察到的结果，不代表其他系统或输入法已经通过。

## 本轮修复

1. 固定本机开发证书代替每次改变身份的 ad-hoc 签名。两份不同二进制满足相同证书要求；实际连续安装多个修复构建，辅助功能和完全磁盘访问记录持续匹配，无需重复管理员认证。证书仅加入当前用户 CodeSigning 信任，私钥和密码在仓库外的独立钥匙串。
2. 设置可直接回到 Apple Notes；正在操作浮动面板时重新打开应用不再强制打开设置。
3. 设置从 AI 入口打开时曾创建空 AppState，导致虚报“需要授权/未运行”；现统一绑定 AppDelegate 的运行状态，同入口复验显示三项已授权。
4. 正文反链已写入却误报核对失败：Notes 的 AppleScript HTML 会漏掉原生笔记链接。校验改为当前正文区间的 AXAttributedString/AXLink，包括写入前的目标校验和写后核对，不再依赖不完整 HTML。
5. XMLDocument(data:) 的 HTML 编码推断会丢失中文/emoji；改为 xmlString 入口，Markdown 复制的中文真实粘贴回读已通过。反链 HTML 辅助核对还覆盖分段标签和实体空格。
6. 字体与对齐使用 AppKit NSPopUpButton。反链面板增加明确关闭按钮。AI 外部点击按会话和事件时间校验，防止旧事件影响新面板；不宣称已解决所有自动化窗口定位差异。

## 尚不能声称完成的覆盖

- 真实物理键盘 Esc/上下键/IME 组合态和快捷键。CUA 定向输入能改 Notes 文本，但本次并未可靠进入应用的全局键盘监听路径；Return/Tab 观察式提交不等同于物理按键拦截全通过。已请求用户补充真实按键结果。
- 硬件多屏、全屏与多个独立 Notes 窗口、不同 macOS/输入法、iCloud 跨设备竞争。
- 密码保护笔记跳过，当前库 21 个复杂内容容器未完全检查。界面明确提示部分覆盖，正文反链在部分覆盖时保留旧来源。
- 系统字体面板呈现、真实服务商账号/Keychain 拒绝、公证/公开分发。当前没有用户真实模型连接，只有本机四协议合成验证。
- Markdown 复制仍属于基础转换，AppleScript HTML 可能漏掉原生链接，附件/图片/复杂对象不保证保真。完整 Markdown 文件交换按用户决定延期。

## 清理和重现

临时模型连接及 /qa1008 模板已通过设置删除，本机服务已停止；工具条恢复默认十项，slash/Markdown/工具条总开关均开启，登录启动保持关闭。A/B/F 等合成笔记保留，未修改用户其他笔记。所有本轮 [DEBUG-*] 插桩已移除。

187 项测试中 186 项执行通过，1 项旧宣传截图用例跳过，29 个套件；启用了当前面板渲染和合成原生 SQLite 用例。原始日志及固定二进制指纹见 [机器收据](verification-0.3.5.json)。
