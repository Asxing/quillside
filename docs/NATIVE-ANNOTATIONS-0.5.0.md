# AppleNotesPro 0.5.0：直接在 Apple Notes 原文批注

2026-10-09。用户明确要求在Apple Notes本身正文添加小气泡，最后在右下角填写整体意见并优化。本版切换到这一使用方式，日常入口不再打开独立修订编辑器。

## 使用

1. 在Apple Notes正文中选一句话，点击浮动工具条的“添加批注”（对话气泡图标）。已有自定义工具条升级后会追加这一项，可在工具条设置调整顺序和显隐。
2. 直接在原句附近的气泡输入意见，保存或⌘↩。正文保持原样；本地保存笔记身份、原句位置和意见。
3. 重复选择其他句子添加意见。也可从右下角“原文批注选项 → 添加当前选区”进入。原文可见段落旁显示气泡标记，同一位置多条意见可在气泡中切换；详细列表在“查看全部批注”。
4. Notes编辑区域右下角出现“整体意见”面板，填写全文要求，点击“统一优化”。处理范围是当前笔记正文，首行标题保留。局部气泡保存时不发送模型请求。
5. 优化完成后，右下角展开修改建议。检查或编辑后“应用到原文”，也可插入后方或复制。应用仍需用户主动点击，Notes原生撤销可恢复。
6. 切换笔记、切换其他应用或关闭面板会收起当前批注会话；重新对该笔记添加批注时恢复本机草稿。原文变化则暂停旧位置，需要菜单“从当前正文重新开始”，旧任务归档保留。

AI浮层里的原“批注修订”入口改为“在Notes上批注”，进入同一原文流程，不再复制候选到另一个修订界面。已有快捷AI结果不会自动当成原文。

## 原生实现与性能

- `NativeNotesAnnotationController`附着Notes正文：原句气泡与右下角输入区使用SwiftUI/AppKit非激活NSPanel；保存的气泡标记使用独立小面板。
- 通过Notes的AX选区与范围几何定位，气泡随着正文滚动更新；只为可见范围建立标记，每次最多32个。旧版独立编辑器的临时划线不再用于此入口。
- 不向Notes插入永久评论对象、不修改正文的下划线格式。气泡属于AppleNotesPro的本机覆盖层，退出应用后不显示，不同步到iCloud。
- 普通打字不增加正文轮询。完整捕获发生在明确添加批注、开始优化、写回时；定位在后台队列合并更新，不进入键盘event tap。
- 原文首次变化时隐藏旧标记、暂停操作，单次检查笔记身份以区分编辑当前笔记与切换笔记；不会每个按键调用Apple Events。
- 输入面板仅在编辑字段/气泡获得焦点时占用输入。短暂丢失Notes编辑器焦点时不把会话误判为关闭。

## 验收记录

合成测试笔记：`APN-AGENT-1009 原文气泡验收`、`APN-AGENT-1009 原文滚动验收`。没有编辑或向模型发送用户真实笔记。

- 在真实Notes中选择原句，浮动工具条“添加批注”打开对应原文气泡；输入并保存，两条意见同时存在，正文无变化。
- 本机合成协议服务记录plan/revise/audit均收到两条批注和Humanizer-zh。右下角显示候选，应用到Notes正文后，标题、数字、末尾emoji保留；一次Notes原生Undo恢复原文。
- 新增第三条原文意见后退出、重启，再进入同一笔记恢复三条意见，三条对应标记均处于当前可见范围。
- 65段合成笔记的第60段保存气泡；滚动离开后可见标记数从1变0，滚回后恢复为1，整体意见会话保持。
- 对测试正文临时追加`STALE-CHECK`，立即显示原文已修改、暂停定位，统一优化禁用；一次Undo撤销该临时改动。
- 最终构建从原文气泡验收笔记切换到滚动验收笔记，旧批注和右下角面板自动收起；原笔记批注继续留在本机。
- 221项测试中220项执行通过，1项旧宣传截图跳过，36套件。新增标题保护与UTF-16范围、生成后继续引用原文、不同笔记/窗口拒绝写入、跨屏面板位置及不可见标记过滤测试。
- Release与严格签名验证通过。原模型配置已完整恢复，临时模型连接删除，本机fixture服务停止。

本次新增原文UI链路使用可控本机合成服务验证，不把固定输出当成模型语义质量证明。原写作内核的真实模型、Humanizer-zh和十批注两轮验证见[0.4.1记录](CREDENTIAL-RESPONSE-0.4.1.md)。本版本没有重新执行真实模型质量测试。

## 已知边界

- 当前批注模式针对Notes正文，表格单元格不是整篇批注范围。含原生对象的范围可能不能整体优化或替换；RTF不可取得、段落结构改变时仍拒绝覆盖，保留插入/复制。
- 原文在批注期间发生修改时，不自动猜测批注新位置，需重新开始；这是保守的定位保护。气泡是本机附加层，不是Apple Notes的原生同步评论。
- 当前任务正文最多200KB，批注最多200条。整体意见会对当前正文的全部启用批注一起处理。
- 窗口与显示器位置有几何测试，当前Mac的滚动有实机证据；多显示器、Stage Manager、所有Notes窗口布局尚未穷尽验收。
- Agent角色、模型/提示词设置拆分仍属于[独立规划](AGENT-ROLES-AND-SKILL-PLAN.md)，不因本次原文交互升级而标成已实现。

## 数据

原文批注草稿按需保存至兼容数据目录的`NotesAnnotationDrafts/`，与此前候选稿批注的`WritingDrafts/`分开，避免对同一笔记采用不同范围时相互覆盖。每个原文任务保存标题以外的正文范围、基线、原句意见与候选历史；它不形成搜索索引或知识库。旧版候选稿草稿不删除。
