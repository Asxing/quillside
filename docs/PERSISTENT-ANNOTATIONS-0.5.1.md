# AppleNotesPro 0.5.1：Notes批注常驻

2026-10-10。修复用户反馈：点击其他位置后原文批注消失。

## 行为

- 点击同一笔记正文、空白、日期或当前笔记的列表项，不关闭批注会话。已保存的气泡标记与右下角整体意见保持。
- 打开的原文备注框也保持显示，普通点击不删除尚未保存的输入。气泡可用自己的×关闭；右下角面板的×才结束当前会话。
- 滚动时，只暂时隐藏离开视野的标记/备注框；返回原句后重新定位。覆盖层不固定在屏幕的旧位置。
- 切换到其他应用、笔记或窗口时暂时隐藏。回到原来的Notes笔记与窗口，自动验证笔记身份和原文，再恢复会话。单个活动会话不会跑到其他笔记上。
- 尚未保存的备注文字随当前进程内的备注框保留；菜单“继续当前批注”可重新获得输入焦点。未保存文字不承诺跨退出/重启恢复；已保存批注继续按既有规则落盘。
- 原文真正发生编辑时，旧位置暂停，保持既有保守写回保护。点击×主动关闭、退出应用、重新开始或应用成功后的行为不变。

## 根因与修复

0.5.0把正文区域外的鼠标点击直接映射为close，应用切换同样close；定位还要求Notes正文一直持有焦点。因此普通窗口操作可以结束会话或让所有标记失去可见条件。

0.5.1将“暂时隐藏”与“结束会话”分开。隐藏时保留目标笔记、事件订阅、输入面板和未保存文字；通过已有窗口/应用事件恢复。定位依赖已确认的笔记身份、原窗口与正文范围，不再依赖光标仍在正文。身份未知或不匹配时只隐藏，不扩大写入权限。新读取只发生在活动会话的窗口/焦点/正文事件，不新增后台定时扫描。

NotesAnnotationPresence提供对应可测试规则；NotesAnnotationReader负责确认上下文和投影；NativeNotesAnnotationController管理保留、暂时隐藏与显式结束。保存和写回仍重新验证原笔记与原文。

## 验证

- 旧逻辑回归测试先得到3项失败、6个断言，覆盖正文外点击结束、应用切换结束、失焦/不同笔记的错误结束。修改后同组通过。
- 在旧版真实UI执行“原文气泡验收→原文滚动验收→原文气泡验收”，得到 returnedToOriginalNoteKeepsSession=false。
- 新版相同路径回到原笔记，右下角面板自动恢复，显示4条已有批注、当前可见4条；其他笔记上不显示这组批注。
- 原生备注框输入临时合成意见后，点击笔记日期以及正文空白，输入仍在；切换笔记/暂时失活后返回原笔记，原未保存意见可继续编辑。
- 验收临时输入通过气泡×关闭，没有加入正式批注；已有4条批注保留，Notes正文未修改。没有发送模型请求。
- 224项测试中223项执行通过、1项旧宣传截图跳过，共37套件；Release构建、安装包与严格签名校验通过。

UI自动化有时会在所有悬浮窗口隐藏时激活AppleNotesPro设置页；此时需重新激活Notes以观察恢复，不能把读取后台控件当作已切回Notes。已在实际激活原Notes笔记后验证恢复，未以后台AX选中作为唯一证据。

## 范围

本版只修复原文批注显示生命周期，模型、Skill、Agent规划及钥匙串策略保持。批注仍是本机覆盖层，不是Notes同步评论；多显示器和全部系统窗口模式尚未穷尽实机覆盖。格式/写回边界见[0.5.0说明](NATIVE-ANNOTATIONS-0.5.0.md)。
