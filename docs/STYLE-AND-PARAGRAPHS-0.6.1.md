# AppleNotesPro 0.6.1：角色风格与段间空行修复

2026-10-11。修复已保留到0.6.3，三个精简角色Prompt的真实模型复验已完成；自动化回归与实际模型/Notes验收分别记录。

## 角色差异

公众号内置规则升级为读者导向短文：从材料中真实变化或疑问切入，用证据、边界和自然过渡推进，不采用笔记标签。个人笔记升级为便于回顾的信息组织：在既有段落内使用观察、依据、边界、待确认、下一步等适用标签和短句，避免对外文章的铺垫和互动开头。两者都保留事实、数字、用户批注和不确定性，不编造故事。

升级只更新与0.6.0内置文案完全一致的公众号/个人笔记；原目录先备份。自定义角色、Skill绑定、快捷动作选择、默认Agent和模型设置保留。历史任务快照不改写；已有旧任务可用“更新当前角色与Skill”获取新版规则。

## 自动处理空行

修订请求明确提供原生段落数量和单换行约束。即使模型仍输出额外空白行，宿主会在复核和展示之前对齐原文的空行布局；写回路径也使用同一规则兜底。

仅当原文与候选的非空段落能一一对应时处理：保留候选中每个非空段落的全部字符与顺序，复用原文的空段位置和段落分隔。不会合并、拆分或删除非空内容。含原生对象、围栏代码或缩进代码的范围不做此归一化；真正改变段落结构仍按已有规则拒绝覆盖。

模型复核看到的正文就是最终预览；无需用户追加提示词或重新生成。发生自动处理时，版本记录formattingNote和界面状态明确说明。
