## 模板入口

模板模型增加可选快捷词，旧 JSON 缺少该字段仍可读取。快捷词不区分大小写，不能重复或占用内置命令。新建默认模板使用 `meeting`、`reading`；已保存的旧模板不被自动改名，可在模板页自行设置。

- Notes 的 slash 菜单动态列出已保存模板，可以用上下键或鼠标选择。
- 输入 `/meeting` 等自定义快捷词，按 Return、Tab 或空格提交，替换该触发串。
- 输入 `/template` 打开独立原生搜索面板，按中文名称或快捷词过滤，Return 插入、Esc 关闭。
- 日期变量在提交时单次展开。插入不调用 LLM，不要求配置模型。

普通行内 slash token 仍以 ASCII 快捷词为入口；中文搜索在自己的 NSSearchField 中进行。该输入框直接查询自身 field editor 的 marked-text 状态，输入法组合期间不会把候选确认/方向键当作面板命令。真实中文输入法行为仍需实测。

动态目录只使用用户配置的快捷词，模板 UUID 不会成为隐式可执行别名，也不显示在产品菜单中。配置成功提交才更新目录；无关模型设置变化不会关闭正在使用的 slash 菜单。

## 插入与失败边界

在激活模板面板之前捕获 Notes 目标，将写入范围限定为完整的 `/触发词`。提交前重新检查 Notes 身份、进程、窗口、正文、编辑元素和实际选区。授权或读取期间改变目标时拒绝使用旧快照。

一次打开的模板面板只允许一次插入尝试；失败后不会自动重试，用户可以复制渲染后的文字或重新捕获。写入尚在进行时拒绝取消/关闭，避免让用户误以为撤回了已经发生的写入。

本版插入纯文本，周围原生内容不做全文回写。原厂模板来源/命名协议仍未获得完整实机证据；富文本、原生表格和附件模板仍属于未完成项。旧的工作台模板预览保留。

## 搜索面板

Notes 内搜索、全局搜索和菜单入口均打开独立面板。搜索框请求初始焦点，支持上下选择、Return 打开、双击打开、Esc 关闭以及刷新。元数据只在打开/刷新时读取；查询和选择使用缓存结果，避免每次 UI 重绘重复排序。

排序优先级为标题完全匹配、标题前缀、标题包含各查询词、摘要及文件夹；同级按置顶和更新时间排序。支持中文、多词、大小写和重音折叠。当前仍搜索标题、摘要和文件夹，不虚构为全库正文搜索。

搜索的数据库入口现在明确检查 schema 与 SQLITE_DONE；读取错误不能作为零条结果。锁定笔记的摘要不返回。晚到的旧加载结果不能覆盖新请求，列表中的系统链接只在用户选择后打开。

## 可配置热键

“设置 → 快捷键 → 搜索快捷键”分别记录 Notes 内与系统全局组合。Esc 取消录入，Delete 清除；支持恢复默认和重试注册。按物理键位保存，并显示录入时的字符。

全局组合仍使用 Carbon 注册单个 hotkey，不依赖全局文本捕获。新组合成功注册并持久化后才释放旧组合；冲突或写盘失败保留旧设置和有效绑定。全局注册失败不阻止修改 Notes 内快捷键。同一组合同时用于两种入口时，已注册的全局路径优先，避免一次按键执行两次。

录入时暂时释放本应用的全局注册，完成、取消、离开窗口或销毁录入控件时恢复。录入期间不会提交另一份设置。系统保留组合、键盘布局切换、录入焦点、实际占用冲突与恢复必须在解锁后实测。

快捷键单独保存于 `~/Library/Application Support/OpenNotes/shortcuts.json`，不包含在“AI 与模板配置”导出中。损坏或未来版本配置会保留原件，普通保存被阻止；显式恢复默认先备份。
