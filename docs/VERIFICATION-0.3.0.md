## 实机边界

本轮设置“通用”实际显示：辅助功能未授权、完全磁盘访问未授权、Notes 自动化已授权。AI 快捷键未打开面板；源码中事件监听在未获辅助功能权限时不启动，故没有将这个现象记为成功。必须为 OpenNotes 授予辅助功能后再验收选区浮条、输入法、真实生成、替换/插入、取消、切换笔记和撤销；反链另需完全磁盘访问。当前没有配置模型连接，后续完整验证可先用本地合成服务，不需要真实密钥。

当前原生视图渲染、会话测试、设置实机通过，**不等于 Notes 内 AI 完整闭环已经实机通过**。模板/正文反链的新非激活面板也尚待真实操作验收。当前 AI 与模板写回仍为局部纯文本，复杂富文本保真不在本轮声称范围。不同 macOS、键盘布局、多窗口/全屏的完整验收仍待进行。

没有新增或修改系统隐私授权，没有改动原有用户笔记。Developer ID、公证、Intel 包、对外发布和真实模型服务验证未进行。
