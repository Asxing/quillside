# 官网多语言

2026-10-13。应用版本仍为0.7.3，此次修改官网。

## 可用语言与页面

- 简体中文：`/zh-CN/index.html`
- 繁體中文：`/zh-TW/index.html`
- English：`/en/index.html`

每种语言包含首页、指南、下载、隐私、开源五页，涵盖导航、按钮、FAQ、元信息、图片说明及交互演示。后续按用户要求，根路径五页改为英文默认入口，GitHub主README也调整为英文；中文README保留在`README.zh-CN.md`。中文仍是模板翻译键及真实模型验收材料的来源语言。

语言菜单跳转到对应页面并保留当前锚点。只将用户主动选择的语言保存在浏览器本地；访问根路径时恢复该语言，显式语言URL始终优先。静态语言链接不依赖JavaScript；禁用存储时脚本捕获失败，不阻止正常导航。

## 内容与来源

界面布局共用HTML模板，简体中文原文作为翻译键，译文在`site/locales/`维护。缺少翻译会让构建失败；网页中的交互提示由同一语言包生成。文本与HTML属性安全转义，示例JSON防止闭合script标签。静态资源共享，使用相对路径及内容版本。

真实模型验收来源仍为中文0.6.3案例。英文是解释性译文，繁体版为转写，页面明确注明不是另一轮模型实测；译文文件记录原文摘要，原材料变化时要求重新审阅。原生App截图保留真实中文内容，英文说明明确标注；FAQ说明官网本地化不代表Mac应用已提供相同语言。

翻译前同步修正Pi内容：新Pi连接的API Key/OAuth凭据使用应用独立本机文件，旧兼容连接仍使用Keychain；指南增加Pi模型与受支持订阅登录，开源页和官网分发补齐Pi/Node许可目录。隐私页说明语言偏好的本地存储。

## 验证

- `python3 site/build.py`：生成15个本地化页面和5个兼容页。
- `python3 site/check.py`：检查页面/语言覆盖、对应页切换目标、hreflang、图片/链接/锚点、动态数据、英文漏译、示例来源与预览发布状态。
- `node --check site/assets/site.js`：语法通过。
- 浏览器实测英文批注保存 → 预设优化 → 应用示例 → 恢复原文，批注内容保留；个人笔记场景及结果文案正确切换。
- 实测英文指南`#models`切到繁体后保留页面和锚点；访问根指南时恢复繁体偏好；显式英文隐私页仍保持英文。
- 实测在页面内跳到`#scenes`后再切换语言，锚点保留。
- 语言菜单支持键盘Enter展开和Escape关闭并恢复焦点，已实测。
- 390px宽度检查三种语言全部15页：无整页横向溢出，没有发现已加载的非懒加载图片损坏。手机端语言菜单三项均可见。
- 桌面英文首页与手机端菜单已目视检查。预览仍是本地网站，尚未公开部署。

证据位于`build/site-i18n/`，包括`responsive-results.json`与页面截图。维护和新增语言方式见`site/README.md`。
