# 官网本地预览 · 2026-10-12

已按 [Magpie 参考方案](MAGPIE-WEBSITE-REFERENCE.md)完成首个可运行的本地版本。使用现有 AppleNotesPro 品牌，没有注册域名、公开仓库、部署网站或更改本机安装的应用。

## 已实现

- 首页：浅色、图文交替的产品展示；首屏强调 Notes 中的划线批注和整体修改。
- 原文批注交互示意：选择原句、编辑并保存意见、查看预设结果、应用到网页示例、恢复原文，批注意见在当前网页内存中保留。
- 三场景：从 0.6.3 真实模型验收文件读取同一原文与三份候选，可切换、展开角色 Prompt 和原文，支持键盘左右键/Home/End。
- 原生 AI 面板：使用 0.6.3 SwiftUI 组件测试渲染图与合成文本，明确标注来源。
- 快捷编辑示例：标题、核对清单、模板切换；正文反链的示意说明。
- 独立页面：快速上手、版本与下载、数据与隐私、开源与反馈。
- 构建：Python 标准库生成五个静态 HTML 页面，复制必要许可。版本读取根目录 VERSION；公开状态与架构信息集中维护。
- 发布状态诚实呈现：尚未提供正式安装包、公开仓库或支持邮箱，不使用假链接。站点预览禁止搜索索引。

应用源码中引导页“所有处理都留在本机”已改为“AI 按需连接你配置的模型服务”，并通过 Swift 编译。该变更尚未重新打包安装，将在后续应用构建中生效。第三方声明同步明确旧知识索引和独立工作台已归档，所有上游版权继续保留。

## 验证

- `python3 site/build.py`：五个页面成功构建。
- `python3 site/check.py`：页面唯一主标题、重复 ID、图片说明、站内链接、资源与锚点、预览发布边界通过。
- `node --check site/assets/site.js`：语法通过。
- `swift build`：应用编译成功；既有 actor 隔离与测试 fixture 资源警告仍存在，不宣称无警告构建。
- CUA 实际浏览器验收：批注保存→预览→应用→恢复通过；三场景切换与键盘切换通过；Prompt 展开、模板示例、五页面导航通过。
- 桌面默认视口、390×844 手机视口与768×1024平板视口查看。手机实际内容宽度375（含滚动条时），平板753；正文宽度与视口一致，没有横向溢出。已载入图片无损坏。
- 浏览器没有观察到 JavaScript error；针对实际 DOM 发现的小字对比度不足已调整。

这是官网与展示内容的验收，没有重新调用真实模型，也没有重做 App 的跨机器验收。网页演示不会操作 Notes、不调用模型；修改意见不会影响固定示例结果，页面明确标注这一点。当前没有实际 Notes 操作录屏，后续正式宣传录制使用合成笔记即可。

## 下一步与用户输入

网站源代码与内容均位于 [site](../site/README.md)，不需要账号即可继续调整。正式公开前需要确定：

1. 正式品牌、发布者、支持邮箱；若改品牌，另做旧配置和权限迁移。
2. GitHub 账号/组织与仓库名。项目介绍按下一轮讨论整理，当前只增加了官网预览入口。
3. 域名与托管归属。当前静态构建不绑定托管商，可直接部署静态文件。
4. Developer Program 会员/团队与本机 Developer ID 认证。正式签名、公证、干净环境安装及升级验证完成后才开放下载。
5. 首发商业方式、语言与兼容范围。建议首发免费公开测试版、用户自行配置模型；尚未把该建议写成收费承诺。

发布清单的详细工作与责任在 [参考方案第6节](MAGPIE-WEBSITE-REFERENCE.md#6-与官网完整版发布准备对齐)。证书、API Key、密码与私有配置不写入公开仓库。
