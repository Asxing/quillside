# Quillside

产品主名为 **Quillside**，官网以 **Quillside Notes** 展示；此前开发名为 AppleNotesPro。

原生 macOS Apple Notes 编辑增强工具。当前本地开发版 **0.7.3**，Swift + SwiftUI + AppKit 原生界面，内置 Pi Agent 引擎，以 ProNotes 的写作增强体验为功能对标。

笔记保存在 Apple Notes；原文搜索使用 Notes；跨笔记 AI 搜索交给外部 MCP/AI 工作流。[当前功能清单](../CURRENT-FEATURES.md) 是交付范围，[产品方案](../PRODUCT-SCOPE.md) 说明反链设计，[验证记录](VERIFICATION.md) 区分代码、测试与实机结果。此前全功能对照保留为研究记录，不等于每项都要实现。

## 当前功能

| 功能 | 行为 |
|---|---|
| 编辑工具条 | AI、字体、粗斜体、下划线、删除线、高亮、链接、对齐、清单；可选列表/引用/等宽/表格，支持显隐与排序 |
| Markdown / slash | 行首快捷格式、原生命令、模板选择与自定义模板快捷词 |
| 原文批注与 Skills | Notes原句气泡、右下角整体意见、整体修订与复核、本机草稿/历史；内置Humanizer-zh |
| AI 编辑 | Notes 旁的原生浮动面板：快捷动作、自定义要求、流式预览、停止/重试、替换/插入；不打开写作工作台 |
| Agent与统一设置 | 模型连接独立；Agent编辑一份角色Prompt并选择Skill；Skill统一管理提示词和技能包；角色直接在Notes切换 |
| 反向链接 | 查看并打开来源；新增正文反链预览/写入，部分覆盖只追加来源，重复更新去重 |
| 基础操作 | 复制笔记链接、现有基础 Markdown 复制、菜单栏、系统外观、登录启动、权限说明 |

**已移出当前构建：** 独立笔记搜索、搜索热键、个人知识库、文件资料导入、全文/语义检索、跨笔记问答。旧代码归档于 `legacy/retired-features/`，不编译、不加载。

**后续再做：** Notes 与 Obsidian 的 Markdown 文件导入导出、附件转移及链接转换。现有“复制 Markdown”不是完整导出，图片和附件仍可能只是占位文字。也不提供后台双向同步。

## 使用

应用启动后留在菜单栏，不自动打开后台。使用流程见 [Notes 内 AI 编辑](../INLINE-EDITING.md)。

1. 从菜单栏“设置…”进入统一设置，在“模型连接”选择Pi服务商、授权方式和模型；在“Agent”设置场景角色，在“Skill”统一维护快捷提示词和技能包。
2. 在 Notes 正文选择文字，点击浮条 AI，或按 `⌥⌘A`。无选区时读取当前笔记，并明确显示“当前笔记”。
3. 点击润色、翻译等动作，或输入自己的要求。生成结果出现在选区附近的同一个面板，允许检查、编辑、停止、重试和复制。
4. 点击“替换选区”或“插入后方”，校验目标后写入 Notes 并关闭面板。无选区只允许插入光标后。取消不会修改笔记；笔记/选区变化会禁用旧结果的写回。
5. 模板在设置中维护，在 Notes 输入 `/meeting` 或 `/template` 使用。正文反链从 Notes 旁的来源面板进入预览和写入。

设置窗口只做配置，没有写作编辑器或模板插入入口。多次打开应用会显示统一设置；日常写作不需要进入它。

既有合成 Notes 验收覆盖 AI 选区/当前笔记预览、替换、插入、取消、撤销和目标失效，以及工具条、九类 Markdown、slash、模板与正文反链。真实模型角色测试按版本单独记录；物理键盘/IME与多屏覆盖仍不完整。

## 权限与本地数据

- Accessibility：读取选区、浮层、格式命令、局部写入。
- Automation → Notes：当前笔记身份及用户触发操作的正文读取。
- Full Disk Access：只读 Notes 数据库，以定位原生笔记和读取反链关系。

权限须针对 Quillside 单独授予，原厂 App 的权限不会继承。应用不会自动开启系统隐私授权。

为兼容已有安装，本地数据目录继续使用 `~/Library/Application Support/OpenNotes/`。`settings.json` 保存非秘密 AI/模板配置；API Key 在 Keychain。`backlink-regions.json` 仅记录应用生成的链接区域及历史版本，用于识别重复、更新及撤销后的区域，不保存整篇笔记副本。历史 `knowledge.sqlite` 和 `shortcuts.json` 不再读取，也不会自动删除。

仅主动选择 AI 动作、提交修改要求或测试连接时才发送模型请求。打开 AI 面板本身不发请求；生成发送捕获的当前内容、指令、系统提示词和写作偏好；不自动检索或加载其他笔记。反链读取和生成不调用 LLM。模型服务是否本地运行由所配置的地址与模型决定。

旧版未修改的默认知识库问答指令会在加载时转成“就当前内容提问”，保留 ID，下次保存才落盘。自定义旧指令保持原样；若仍依赖 `{sources}`，生成时明确提示修改，不偷偷扩大输入范围。AI/模板配置的 JSON 备份导入导出保留，它与暂缓的笔记文件导入导出是不同功能。

## 开发与构建

要求 macOS 14+、Swift 6.2 工具链。当前本机 macOS 26.5.2、Apple Silicon；其他组合未实机覆盖。

```bash
./scripts/verify-stage1.sh
./scripts/bundle-app.sh release
codesign --verify --deep --strict build/Quillside.app
```

验证脚本使用临时 SQLite 与 localhost 合成模型服务，不读取真实 API Key。0.7.0报告261项原生测试，257项执行通过、4项因截图或实机数据库条件未启用而跳过；另有8项Pi运行时集成测试通过；这与另外进行的真实模型实机验收分开记录。

本机已使用专用开发证书；构建脚本自动读取仓库外的本机签名配置。签名材料不进入源码包。没有本机签名配置时使用可用 Apple Development 身份，最后才回退 ad-hoc；明确设置 `OPENNOTES_CODE_SIGN_IDENTITY=-` 仍会选择 ad-hoc 并导致权限可能失效。详见 [开发签名](../LOCAL-DEVELOPMENT-SIGNING.md)。当前包未 Developer ID 公证或公开发布。
