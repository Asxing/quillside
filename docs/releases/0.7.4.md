# Quillside 0.7.4

Quillside is a native writing companion for Apple Notes: annotate passages, revise with your chosen Agent and Skills, review the draft, and apply it with native undo.

- Publish a clearer Chinese/English README, current user/developer guides, and explicit privacy information for Pi credentials versus legacy Keychain connections.
- Add tag-triggered release automation for source previews, explicitly unnotarized tester builds, and notarized distributions.
- Validate version/tag agreement and checksums before publishing; update GitHub Pages from published release metadata.
- Fix source scanning under parent folders named `build`, refresh Pi dependencies when lockfiles change, and document the pinned Node toolchain.
- Keep the unified Quillside logo and three-language website.

The app interface is primarily Chinese. Current on-device coverage is Apple Silicon/macOS 26.5.2. Intel distribution, broader input-method/multi-display coverage, and clean-user official-install testing remain incomplete. Automated regression does not replace these checks.

This release does not add a knowledge base, separate search, MCP/tools, or automatic updates. Read the release header for whether this particular artifact is source-only, unnotarized, or notarized.
