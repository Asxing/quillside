# Quillside 0.7.6 — automated app delivery

Tag releases now publish installable Apple Silicon packages with prominent download links and update the website automatically.

- Build DMG and ZIP tester packages, including the native app, Pi, Node, icons, Skills, and license notices.
- Generate the Release title and top-of-page download links from verified artifacts, with actual file sizes and SHA-256 links.
- Verify GitHub received every asset with the expected size and digest before publishing the draft; confirm the public Release afterward.
- Deploy GitHub Pages from the default branch after the Release workflow succeeds. Resolve published release metadata at build time and preserve the stable channel when one exists.
- Check the public release metadata and all English, Simplified Chinese, and Traditional Chinese download pages against the deployed artifact. Retry propagation delays and fail the Pages run if the public site remains stale.

This is an **unnotarized tester build**, suitable for Apple Silicon. First launch may require per-app approval in macOS. Developer ID signing, notarization, clean-user installation, and wider compatibility remain separate release work. App editing and AI behavior are unchanged.

中文：本版固化自动发版交付，推送标签后自动打包DMG/ZIP、上传并生成Release顶部下载入口，随后自动更新官网并验证公开页面。仍是未公证测试版，应用编辑与AI行为保持不变。
