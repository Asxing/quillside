# Quillside 0.7.7 — automated Mac packages and website updates

- Tag pushes build and upload Apple Silicon DMG and ZIP tester packages, with Pi, Node, Skills, and license notices included.
- Release titles and top-of-page download links are generated automatically from verified artifacts, including actual file sizes and SHA-256 links.
- GitHub draft assets are verified by Release ID before publication. The tag-based API cannot resolve unpublished drafts; the pipeline now handles this explicitly and verifies the final public Release afterward.
- A successful Release triggers GitHub Pages on the default branch. The public version, checksums, and English, Simplified Chinese, and Traditional Chinese download pages must match the deployed artifact before the website workflow succeeds.

This is an **unnotarized tester build** for Apple Silicon. First launch may require per-app approval in macOS. Developer ID signing, notarization, clean-user installation, and wider compatibility remain separate release work. App editing and AI behavior are unchanged.
