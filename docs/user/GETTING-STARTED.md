# 开始使用

Quillside仍处于开发者预览阶段。可下载无需开发工具的`UNNOTARIZED` DMG或ZIP测试包；自行构建见[构建指南](../development/BUILDING.md)。发布页如提供`UNNOTARIZED`包，它只供愿意承担测试风险的使用者试用，不是已公证正式版。

## 安装与权限

启动后从菜单栏进入设置。Accessibility用于选区与编辑，Automation → Notes用于当前笔记识别及主动操作时读取，Full Disk Access用于只读Notes定位与反链。系统授权由用户在macOS窗口完成。

对来源可信的未公证App，macOS可能提示无法验证开发者。Apple提供“系统设置 → 隐私与安全性 → 仍要打开”的单App确认流程；不同系统或受管理设备可能限制该操作。[Apple说明](https://support.apple.com/en-us/102445)。不建议关闭全局Gatekeeper、递归清除系统保护属性或导入他人的开发签名私钥。

## 模型与写作

1. 设置 → 模型连接：通过Pi选提供方、保存API Key或完成支持的订阅登录，选择模型再测试。
2. Agent：选公众号、个人笔记、汇报或自定义角色Prompt；Skill提供可选方法。
3. Notes中选中文字，点击AI或按`⌥⌘A`。选择动作或提交要求才开始生成。
4. 多处修改时，在原文附近添加批注，右下角填写整体意见，一起优化。
5. 检查候选后确认写回；需要恢复时用Notes原生撤销。

未经测试的格式、输入法、多窗口或长文场景先使用合成内容验证。更新临时签名App可能需要重新授权。配置数据不会因为删除App自动清除，详见[隐私说明](PRIVACY.md)。
