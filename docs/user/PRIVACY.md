# 数据流与隐私

笔记正文由Apple Notes保存；Quillside保存角色、Skill、模板、模型设置、批注及候选历史。后两项可能含笔记正文，位于本机应用数据目录。为升级兼容，目录仍为`~/Library/Application Support/OpenNotes/`。

新Pi连接的API Key和OAuth令牌由Pi AuthStorage写入本应用独立`Pi/auth.json`，文件权限0600、目录0700；这不是Keychain。旧兼容连接继续使用macOS Keychain。不读取Codex、Magpie或用户全局Pi凭据。

主动AI生成、继续修改或连接测试才发起模型请求。本轮可能包含选区/当前笔记、批注、整体要求、角色Prompt、启用Skill、上一候选及必要上下文；不自动检索其他笔记。远程服务会收到这些材料，其保留与计费遵循服务方政策。

任务结束、取消、离开笔记、休眠或退出会停止本地请求与子进程；不能撤回远端已收到的数据，也不保证远端立即停止计费。草稿恢复不会自动重新生成。

模型设置中的“退出授权”移除本应用对应提供方的凭据；删除App不保证删除本机配置、Pi授权、草稿或旧Keychain条目。清理前先备份需要的内容，不要删除Apple Notes自己的数据库。

官网计划使用GitHub Pages。没有自建遥测、广告或远程字体；GitHub会为安全记录访问者IP。浏览器只保存语言偏好，演示内容保留在内存，刷新即清空。不要在Issue或截图中公开真实笔记和凭据。
