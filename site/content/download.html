0.6.4 · Quillside 品牌更新

产品主名统一为 Quillside，官网以 Quillside Notes 展示。新版羽毛笔与便笺标志用于应用和官网；旧模型连接、批注草稿与正文反链记录保留兼容处理。

0.6.3 · 更简单的 Agent

Agent 由名称、角色 Prompt 和所选 Skills 组成。模型连接单独配置，旧的多栏角色描述合并成可直接编辑的 Prompt，并保留配置备份。

在同一份示例材料的三场景验收中，每个场景的五条批注均保留，候选结果首轮写回与预览一致，一次原生撤销恢复原文。这个结果来自受控材料，不代表所有文章、模型与格式都有相同效果。
