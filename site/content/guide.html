快速上手

从你熟悉的 Notes 开始。

安装一次，配置好需要的能力。之后的编辑、批注和 AI 修改，都在笔记旁完成。

当前官网为预览版本。正式安装包准备进度与实际支持范围见版本与下载。

01 · 安装与权限

正式版本发布后，从官网下载对应安装包，打开后将应用放入 Applications。启动 Quillside 后，可以从菜单栏打开设置。

系统权限用于什么在哪里管理
辅助功能识别 Notes 窗口与选区、显示工具条、执行格式和写回操作。系统设置 → 隐私与安全性 → 辅助功能
自动化 → Notes识别当前笔记，并在用户操作时读取正文。macOS 会在首次需要时询问。系统设置 → 隐私与安全性 → 自动化
完全磁盘访问只读访问 Notes 数据库，用于原生笔记定位及反链关系。系统设置 → 隐私与安全性 → 完全磁盘访问

系统授权需要你在 macOS 窗口中完成。授权后若状态没有更新，可重新打开应用。你可以随时在系统设置撤回权限，对应功能会受到限制。

02 · 配置模型，再选角色

  1. 打开“设置 → 模型连接”，通过 Pi 选择服务商与模型，保存 API Key 或使用受支持的 ChatGPT 订阅登录，再测试连接。旧兼容连接保留在单独的配置区域。
  2. 打开“Agent”，选择公众号、个人笔记或汇报，也可以创建自己的角色。每个角色由名称、一份角色 Prompt 和所选 Skills 构成。
  3. 在“Skill”中管理快捷提示词和技能包。例如启用 Humanizer-zh，为当前角色补充去除生硬表达的写作方法。

模型费用和服务条款由你选择的提供方决定。当前应用不包含模型额度；本地服务需要你自行运行。普通编辑工具不要求配置 AI。

03 · 完成第一次 AI 修改

  1. 在 Apple Notes 正文中选中一句话，点击浮动工具条的 AI，或使用 ⌥ ⌘ A。
  2. 选择润色等动作，或输入自己的修改要求。点击生成时才发送模型请求，打开面板本身不会发送。
  3. 检查候选结果，可继续修改，再选择“替换选区”或“插入后方”。没有选区时只允许插入。
  4. 如果需要恢复，使用 Notes 的原生撤销。切换笔记、改变目标等情况会阻止旧结果继续写入，请确认当前目标后操作。

04 · 多处批注，一起优化

  1. 在 Notes 原文中选中需要调整的文字，选择添加批注。
  2. 在原句旁的小气泡中写下具体意见，保存后继续选择其他句子。
  3. 在编辑区右下角填写整体意见，选择本轮的 Agent，然后点击“统一优化”。
  4. 查看修改建议和各条意见的处理情况，确认后“应用到原文”。批注与草稿保存在本机，不承诺跨设备同步。

可以直接在 Notes 中切换写作角色。角色负责表达视角，Skills 提供额外方法。当前版本不执行 MCP 或外部工具，也不会自动检索其他笔记。

05 · 将反向链接放进正文

打开当前笔记的反链来源列表，选择“预览正文反链”，检查来源后再写入。应用会在笔记末尾保存可点击的来源链接，日后可以直接在 Notes 中打开。

来源列表需要主动更新。如果你手工编辑了应用生成的区域，或预览后目标发生变化，应用会停止覆盖。反链功能不是全库搜索，也不提供后台双向同步。

遇到问题时

选中文字后没有出现工具条

先确认 Notes 正文处于可编辑状态，Quillside 正在运行，辅助功能授权指向当前 Applications 中的应用。打开设置检查工具条开关；避免同时运行多个版本。

模型连接测试失败

核对协议、完整服务地址、模型名称和 API Key。如果使用本地模型或网关，先确认服务已启动。远程服务的额度、限制和访问条件由提供方决定。

停止生成后会发生什么？

当前请求会取消，旧回复不应继续写回。本机草稿保留；重新打开不会自动联网。取消请求不等于服务方已删除此前收到的内容或免除已经产生的费用。

可以导出到 Obsidian 吗？

完整 Markdown 文件导入导出还在后续范围。已有基础 Markdown 复制不等于完整导出，附件和图片可能仅有占位内容。

如何反馈问题？

参见反馈说明。请准备版本、macOS 版本和复现步骤，先将截图中的私人笔记和密钥隐藏。
