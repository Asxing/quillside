许可与来源

当前项目采用 MIT License，保留实际使用代码的原始版权声明。独立品牌不改变上游许可义务。

  • NotesPlus：原生编辑增强、窗口跟踪、Markdown / slash 等基础。
  • NotesBridge：选取 Notes 正文与属性解码结构，适配本项目。
  • Yams 与其包含的 LibYAML：YAML Skill 元数据解析，分别保留许可。
  • Humanizer-zh：作为可选 Skill 提供，保留来源与许可证。
  • Pi Agent / Node.js：内嵌模型运行时，保留各组件的原始许可。详见 Pi / Node 许可清单。

完整来源及范围见第三方声明。本项目不包含 ProNotes 的安装包、图标或原厂提示词。

让反馈容易复现

普通问题通过 GitHub Issues 反馈，安全问题使用仓库的私密报告入口。报告问题时，提供下面的信息会更有帮助：

  1. 应用版本、macOS 版本、芯片架构及 Notes 界面语言。
  2. 从打开笔记到出现问题的具体步骤、预期和实际结果。
  3. 是否每次出现，是否涉及输入法、多窗口、表格或附件。
  4. 一份可以安全公开的最小示例。截图中先隐藏私人内容与凭据。

涉及笔记写回或数据安全的问题，应先使用合成材料复现。可利用漏洞请使用 GitHub 私密安全报告，不要在公开问题中披露细节。

协作方式

贡献规则、Issue 模板和维护范围已在仓库说明。欢迎可复现的问题、文档与翻译建议；涉及 Notes 写回、权限及数据迁移的改动，需要专门验收。

当前目标集中在 Notes 内编辑体验。独立知识库、独立搜索和后台双向同步不属于项目方向；MCP / Tools 与完整文件导入导出仍在后续范围。
