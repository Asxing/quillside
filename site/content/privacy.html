知道数据去了哪里。

Quillside 是本机运行的 Notes 增强工具。是否向远程模型发送内容，取决于你配置的连接和主动触发的 AI 操作。

说明日期：2026 年 10 月 13 日，适用于当前 {{VERSION}} 开发版。正式发布时需补充发布主体、联系渠道与最终服务条款。

本机保存的内容

  • 笔记正文继续由 Apple Notes 保存与管理。
  • 模型连接、角色 Prompt、Skills 和模板保存在本机。新版 Pi 连接的 API Key 与 OAuth 凭据保存在本应用独立的本机凭据文件中；旧兼容连接仍使用 macOS 钥匙串。
  • 批注、引用原句、修订草稿与候选历史可能包含笔记正文，保存在本机，用于返回和恢复修订。
  • 反链功能只读 Notes 数据库；应用记录自己生成的正文链接区域及历史，用于识别更新、去重和撤销。

什么时候向模型发送数据

主动生成、继续修改、统一优化或测试连接时，应用才会发起对应模型请求。打开面板和恢复草稿不会自动发起生成。

生成请求可能包含捕获的选区或当前笔记、相关上下文、批注意见、整体要求、角色 Prompt、启用的 Skill 和上一轮候选。无选区时会标识使用当前笔记；不会为了本轮写作自动搜索其他笔记。

如果连接指向远程服务，上述材料将离开本机。服务方可能保留请求日志或内容，其处理方式与保存期限取决于该服务的政策。用户自备 API Key 不意味着所有数据都只在本地处理。

取消与会话

停止生成、关闭面板、离开笔记、电脑休眠或退出应用会触发任务取消，应用也限制无进展时间与总时长。草稿仍留在本机，恢复不自动联网。

取消会阻止本地继续等待和应用过期结果，但无法撤回远程服务已经收到的内容，也不保证远程服务立即停止计费或删除日志。

权限与控制

辅助功能用于选区和编辑操作；自动化权限用于当前 Notes 身份及用户触发的正文读取；完全磁盘访问用于只读笔记定位和反链。权限可在 macOS 系统设置中撤回，详细路径见授权指南。

官网演示

当前官网演示使用合成笔记和预设结果，只在浏览器内存中运行。它不读取 Apple Notes，不调用模型，不保存你在演示中输入的批注。刷新页面会清除这些输入。

当前静态站点没有接入分析、广告或远程字体。官网计划使用 GitHub Pages 托管；上线后，GitHub 会记录访问者的 IP 地址用于安全目的，具体处理方式见 GitHub 隐私声明。GitHub Privacy Statement ↗

网站只在本机浏览器保存你选择的语言，不保存演示批注，也不将语言偏好发送给分析服务。清除网站数据即可移除该偏好。

卸载与保留数据

删除 App 不一定同时删除本地配置、草稿或钥匙串条目。为兼容已有版本，当前数据目录仍为 ~/Library/Application Support/OpenNotes/。若计划移除数据，请先备份需要保留的配置与修订内容；卸载不会自动删除 Apple Notes 中的原始笔记。
