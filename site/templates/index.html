你可能还想知道

需要把笔记搬到新的应用吗？

不用。笔记继续由 Apple Notes 保存与管理，日常修改就在 Notes 中完成。批注与修订草稿由 Quillside 保存在本机。

必须使用 AI 吗？

不用。工具条、快捷格式、slash 命令、模板和反向链接可以单独使用。使用 AI 时需要配置模型服务，远程服务可能由提供方收费。

Prompt、Agent 和 Skill 怎么配合？

一个 Agent 包含名称、角色 Prompt 和选择的 Skills。Prompt 决定表达视角，Skill 补充写作方法；模型连接单独配置。当前版本不提供 MCP 或工具执行。

支持哪些 Mac？现在可以下载吗？

当前准备的是 Apple Silicon 版本，本机已测 macOS {{TESTED_MACOS}}。更广泛兼容性和正式签名公证仍在准备，发布页会说明实际可用的版本。

网站语言会改变 App 的界面语言吗？

不会。网站语言只影响这些介绍与演示页面。目前 Mac 应用界面主要为中文；多语言官网不代表应用已经提供同样的界面语言。

这是 Apple 官方产品吗？

不是。Quillside 是独立开发的 Notes 增强工具，与 Apple 没有隶属关系。
